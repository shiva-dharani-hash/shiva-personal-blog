# Shiva's Digital Journal

A responsive personal blog built using HTML and CSS.

## Files

- `index.html` - Home page
- `about.html` - About page
- `blog.html` - Blog posts
- `projects.html` - Project showcase
- `contact.html` - Contact page
- `css/style.css` - Main stylesheet

## Run locally

1. Download/extract the project.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.

For the easiest development experience in VS Code, install the **Live Server** extension and choose **Open with Live Server**.

## Customize

Replace:
- `your-email@example.com` in `contact.html`
- LinkedIn URL
- GitHub URL
- Text in the About, Blog and Projects pages
- The `S` profile placeholder with your own photo if desired

## Deploy with GitHub Pages

1. Create a GitHub repository named `shiva-personal-blog`.
2. Upload all project files.
3. Go to repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide your live website URL.

## Deploy with Netlify

Create a new site in Netlify and drag the project folder into the deployment area.

No backend or database is required for the current version.
